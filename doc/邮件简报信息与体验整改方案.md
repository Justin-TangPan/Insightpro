# 邮件简报：五大业务情报集成看板

> **实施状态（2026-10-27）**：1.1.0 已上线每日简讯、邮件预览/发送、邮件订阅与 HTML 快照追溯。本文记录的原始设计目标；实际发送调度、快照版本绑定和后台操作以当前代码及[版本日志](../log/versions.md)为准。

## 目标

读者在约两分钟内了解五个业务板块的近期核心信息，并能点开代表条目核对来源。邮件采用白色背景、灰色层级和系统字体，不使用绿色、雷达图或外部图片。

## 信息结构

1. 刊头：日期、五板块简报标题和统计范围。GitHub、AI 应用、解决方案、厂商动态覆盖近 7 天；社区为当前热榜观察。
2. 五张纵向板块卡：固定顺序为 GitHub 技术、AI 应用、解决方案、社区洞察、厂商动态。每张卡先用一句话概括总体判断，再聚焦一个近期最值得分析的来源，展开入选原因、已确认的事件事实、可能的业务影响及证据边界，最后提供原始来源和板块入口。
3. 页尾：社区发布时间口径，以及核实原始来源的提示。

今日板块分析取 `board_daily_insights` 已缓存结果，邮件生成不启动 AI 任务。邮件与板块页面共用 `judgment` 和 `focus` 字段；焦点链接绑定生成时选中的真实来源。当某板块分析未完成时，以近 7 天雷达事件提供来源和站内入口，并明确标注“分析待更新”。原始链接仅允许 HTTP(S)。

## 发送规则

每天北京时间 10:05 后，五板块当天分析全部完成即可发送；若分析未能全部完成，11:30 起使用上述来源兜底。人工预览和测试发送可随时查看当前状态。社区热榜无逐条可核实的发布日期，不写成“今日发布”或“近 7 天新增”。

## 视觉与验收

邮件宽度最多 600px，单列排版、白底、灰色细分隔线、深灰文字。标题 25px、板块标题 18px、正文 14–15px、辅助文字至少 12px；不用 JavaScript、SVG 或图片。HTML 和纯文本均保留来源入口。验证五板块顺序、真实链接、空状态、等待与兜底发送、中英文标签及 375px 手机宽度。
