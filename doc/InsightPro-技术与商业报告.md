## 一、业务架构

### 1.1 业务场景

InsightPro 面向**云服务商业市场**，解决业务决策者在日常工作中面临的核心痛点：

| 痛点 | 传统方式 | InsightPro 解决方案 |
|------|----------|---------------------|
| 行业动态分散，需逐个网站手动浏览 | 人工浏览 10+ 网站/天 | 6 大数据源自动爬取，每日 9:00 统一更新 |
| 竞品分析耗时，需手动整理各厂商动态 | 人工整理 2-3 小时/次 | 5 大云厂商动态自动采集，按厂商分类展示 |
| 政策法规滞后发现，错过商机窗口 | 依赖人工关注政府网站 | 国务院/工信部政策实时爬取，每日推送 |
| 招标信息获取不及时 | 依赖招投标网站人工搜索 | 多行业招标信息聚合，AI 分析高价值标段 |
| 技术趋势判断依赖个人经验 | 手动浏览 GitHub/CSDN | GitHub Trending 日/周/月三维度实时追踪 |
| 商业简报制作耗时 | 人工编写 1-2 小时/份 | 每日自动生成洞察简报，邮件定时推送 |

### 1.2 适用人群

| 角色 | 使用场景 | 核心价值 |
|------|----------|----------|
| **业务领导** | 每日晨会前快速浏览市场全貌 | 5 分钟掌握 9 大行业 + 5 大竞品动态 |
| **销售团队** | 寻找目标客户和商机窗口 | 招标信息雷达 + 需求信号挖掘 |
| **市场团队** | 监测竞品动态和行业趋势 | 友商产品/案例/策略自动追踪 |
| **解决方案架构师** | 了解技术趋势和客户需求 | GitHub 热点 + 行业需求信号 + AI 分析 |
| **高层管理者** | 宏观市场判断和战略决策 | 数据大屏 + 深度研报 + 市场热力图 |

### 3.3 核心技术优势

#### 1. 爬虫化：从"人工采集"到"自动采集"

```
传统模式：                        InsightPro 模式：
人工浏览网站                       6 大爬虫并行采集
    ↓                                ↓
手动复制粘贴                       自动解析 + 结构化
    ↓                                ↓
整理到 Excel                       自动入库 SQLite
    ↓                                ↓
邮件分发                           API 实时查询 + 邮件推送
```

- **6 大数据源并行爬取**：ThreadPoolExecutor 并发，总耗时 < 2 分钟
- **多策略降级**：API → HTML 解析 → 数据库缓存 → 空数据提示
- **自动去重**：唯一索引 + INSERT OR IGNORE，零重复数据
- **定时调度**：APScheduler 7 个定时任务，无需人工干预

#### 2. 大数据化：从"零散信息"到"结构化资产"

- **10+ 数据表**：覆盖新闻、政策、竞品、招标、需求、埋点等维度
- **30 天自动清理**：防止数据库膨胀，保持查询性能
- **历史追溯**：GitHub Trending 支持日/周/月三维度回溯
- **实时聚合**：首页看板从多个表实时统计，数据零延迟

#### 3. AI 增强：从"人工分析"到"智能分析"

- **RAG 架构**：DeepSearcher + Qdrant 向量检索，回答基于真实数据
- **5 个知识集合**：平台知识、需求信号、竞品新闻、GitHub 热点、政策法规
- **深度研究**：支持多轮迭代检索，max_iter 可调
- **智能客服**：RAG 增强的对话式问答，支持流式输出

### 3.4 与传统爬虫方案对比

| 维度 | 传统爬虫脚本 | InsightPro |
