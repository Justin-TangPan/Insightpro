# 商业洞察平台（InsightPro）项目汇报

> 版本：v0.3.0 | 汇报日期：2026-08-24

---

## 一、项目背景

### 1.1 行业背景

当前，全球云计算市场持续高速增长。据 Gartner 预测，2026 年全球公有云服务市场规模将突破 **1 万亿美元**，中国云服务市场规模预计突破 **6000 亿元人民币**。云服务厂商之间的竞争已从"资源层"延伸至"价值层"，业务决策者需要更加精准、实时的市场情报来支撑战略规划与客户拓展。

与此同时，**AI 大模型技术**的爆发式发展为商业分析带来了全新范式。传统的市场调研、竞品分析、政策解读等工作，正在被 AI 驱动的自动化洞察所替代。**检索增强生成（RAG）** 技术的成熟，使得 AI 能够基于企业私有知识库进行深度分析，而非泛泛而谈。

### 1.2 政策驱动

近年来，国家密集出台多项与云服务直接相关的政策法规，深刻影响着云服务市场的走向：

| 政策领域 | 核心内容 | 对云服务的影响 |
|----------|----------|----------------|
| **等保 2.0** | 网络安全等级保护制度强制执行 | 所有上云客户必须满足安全合规要求，催生合规服务需求 |
| **信创替代** | 核心技术自主可控战略加速推进 | 政企客户优先采购国产云服务，华为云等厂商迎来政策红利 |
| **数据出境安全评估** | 跨境数据流动监管趋严 | 跨国企业需重新评估云架构，本土云厂商获得竞争优势 |
| **行业数字化补贴** | 多省推行数字化转型专项资金 | 降低中小企业上云门槛，扩大云服务市场容量 |

这些政策既是机遇也是挑战——**谁能快速解读政策、把握窗口期，谁就能抢占市场先机**。

### 1.3 业务痛点

在日常业务工作中，云服务市场的业务决策者面临以下核心痛点：

1. **信息分散**：行业动态散落在数十个信息源（新闻网站、政策公告、技术社区、招标平台），人工收集耗时耗力
2. **分析滞后**：竞品分析、政策解读依赖人工撰写，从信息获取到分析产出往往需要数天
3. **商机遗漏**：招标信息、客户需求信号发现不及时，错过最佳跟进窗口
4. **知识孤岛**：团队积累的行业知识、客户案例、竞品情报缺乏结构化沉淀，难以复用

**核心诉求**：需要一个一站式、智能化的商业洞察平台，实现从"数据采集 → 智能分析 → 成果分发"的全链路自动化。

## 三、实践方案

### 3.1 整体架构

平台采用 **前后端分离 + AI 中台** 的技术架构，分为五层：

```
┌─────────────────────────────────────────────────────────────────┐
│                        展示层                                     │
│    Next.js 14+ · React 18 · Tailwind CSS · Recharts             │
│    11 个业务页面 · 数据大屏 · AI 对话界面                          │
├─────────────────────────────────────────────────────────────────┤
│                        接入层                                     │
│    Next.js API Routes (前端代理) + FastAPI (后端服务)              │
│    30+ 个 REST API · 流式 SSE 推送                                │
├─────────────────────────────────────────────────────────────────┤
│                        业务层                                     │
│    数据采集引擎 · AI 分析引擎 · 邮件服务 · 埋点服务                 │
│    APScheduler 定时调度 · 5 个自动化任务                           │
├─────────────────────────────────────────────────────────────────┤
│                        AI/RAG 层                                  │
│    DeepSearcher · Qdrant (向量DB) · SentenceTransformer          │
│    DeepSeek-V3 (LLM) · 5 个知识集合 · 跨集合语义检索              │
├─────────────────────────────────────────────────────────────────┤
│                        数据层                                     │
│    SQLite (业务数据) · Qdrant (向量数据) · 文件存储                │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 核心模块说明

#### 3.2.1 智能数据采集

```
外部数据源                采集引擎                存储层
┌──────────┐          ┌──────────────┐          ┌──────────┐
│ GitHub   │─────────▶│  BeautifulSoup│─────────▶│  SQLite  │
│ 百度热搜  │─────────▶│  Requests    │─────────▶│  数据库   │
│ 招标平台  │─────────▶│  多策略降级   │─────────▶│          │
└──────────┘          └──────────────┘          └──────────┘
                              │
                              ▼
                      ┌──────────────┐
                      │ APScheduler  │
                      │ 定时任务调度   │
                      │ 每日自动执行   │
                      └──────────────┘
```

- **多源采集**：支持 HTTP 爬虫、API 调用、预置数据池等多种采集方式
- **降级策略**：实时采集失败时自动降级到本地缓存，确保数据可用性
- **定时调度**：5 个定时任务覆盖早 8:00 到早 9:05 的数据采集窗口


**5 个知识集合**：

| 集合 | 内容 | 用途 |

| `demand_signals` | 行业需求信号 | 需求趋势分析 |
| `competitive_news` | 友商动态新闻 | 竞品情报检索 |
| `github_trending` | 技术趋势数据 | 技术热点问答 |
| `policies` | 政策法规信息 | 政策解读分析 |

### 3.3 功能展示

#### 首页 — 今日商业洞察

聚合 8 大子模块摘要，一屏掌握全貌：
- 7 格看板导航：行业、热点、友商、政策、机会、快讯、AI 分析
- 6 个模块预览卡片，每个展示 3 条核心摘要
- 百度实时热搜（5 分钟自动刷新）
- 今日数据概览 + 系统状态监控

#### 友商洞察 — 场景化竞争分析

覆盖 6 大竞争场景，每个场景包含：
- 对手标识 + 市场规模
- 3 项具体差距（精确到友商能力数据 + 严重等级）
- 4 条可执行落地策略
- 紧迫度时间窗口

#### 数据大屏 — 全局监控

- 4 个 KPI 卡片 + 4 个 Recharts 可视化图表
- PV/UV 实时统计 + 页面访问排行
- 预警监控 + 服务健康度 + 实时流量

#### AI 智能客服 — RAG 增强问答

基于企业知识库的智能对话，支持：
- 跨 5 个知识集合的语义检索
- 流式输出，实时展示回答过程
- 上下文感知的多轮对话

## 五、总结与展望

InsightPro 商业洞察平台已完成 MVP 阶段建设，实现了 **"数据采集 → AI 分析 → 可视化展示 → 自动分发"** 的完整闭环。平台覆盖 9 大行业、5 大竞品、6 大政策领域，通过 RAG 技术实现了基于企业知识库的智能问答和深度分析能力。

**核心竞争力**：
- **AI 原生**：全流程 AI 赋能，从数据采集到报告生成全链路智能化
- **RAG 架构**：基于企业私有知识库的深度分析，确保回答准确可靠
- **自动化运营**：5 个定时任务 + 每日邮件简报，实现零人工干预的日常运营
- **全景覆盖**：从行业宏观到招标微观，从技术趋势到政策法规，一网打尽

**下一步规划**：
1. 对接真实数据源（招标平台、行业报告、政策公告等）
2. 实现用户认证与权限管理
3. 迁移至 PostgreSQL + pgvector，支撑更大规模数据
4. 实现 PDF/Markdown 报告一键导出
5. 容器化部署 + CI/CD 流水线，提升运维效率
