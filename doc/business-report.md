## 一、项目概述

**InsightPro** 是一款 **AI 驱动的端到端商业洞察与分析平台**，面向云服务商业市场（中长尾、腰部行业客户）的业务决策者。平台通过实时数据采集、AI 深度分析和可视化仪表盘，帮助用户快速获取行业动态、竞争分析、政策法规和市场机会，实现从"数据输入 → AI 分析 → 成果落地"的完整闭环。

### 核心价值主张

| 维度 | 描述 |
|------|------|
| **目标用户** | 云服务商业市场的业务领导、销售/市场团队、解决方案架构师 |
| **核心痛点** | 行业信息分散、竞品分析耗时、商机发现滞后 |
| **解决方案** | 一站式 AI 洞察平台，覆盖 9 大行业、5 大竞品、6 大政策领域 |
| **差异化** | RAG 增强的智能问答 + 招标商机雷达 + 每日自动邮件简报 |

## 二、业务功能矩阵

平台包含 **11 个核心功能模块**，分为三大板块：

### 2.1 市场洞察板块

| 模块 | 路径 | 功能说明 |
|------|------|----------|
| **今日洞察** | `/` | 首页仪表盘，聚合 8 大子模块摘要，展示百度实时热搜、今日数据统计、系统状态 |
| **行业全景** | `/insights/industry` | 覆盖政务、制造、医疗、金融、教育、交通、能源、零售、农业 9 大行业，含行业热度、需求趋势、政策驱动分析 |
| **案例库** | `/insights/industry/cases` | 5 大行业深度案例（三一重工、省级医疗集团、省会城市交通、农商行信创、连锁便利店），含友商对比 |
| **技术热点** | `/insights/hotspots` | GitHub Trending 实时监控，支持日/周/月维度，历史数据追溯，每日自动采集 |
| **友商洞察** | `/insights/competitors` | 6 大场景分析（出海、AI平台、开发者、SaaS、性价比、数字化），对比 AWS/Azure/阿里云/腾讯云/火山云 + 华为云 |
| **政策法规** | `/insights/policy` | 等保 2.0、信创替代、数据出境、OPC、数字化补贴、SOC 6 项政策追踪 |
| **商业快讯** | `/insights/news` | Reuters/Bloomberg/财新网/Wired 实时新闻聚合 |

### 2.2 商机发现板块

| 模块 | 路径 | 功能说明 |
|------|------|----------|
| **市场情报** | `/insights/market` | AI 驱动市场全景分析，9 大行业热度矩阵（需求/竞争/政策三维评分），AI 生成行业深度分析 |
| **需求挖掘** | `/insights/demand` | 行业需求信号采集（政策信号、招标信号、行业报告、技术趋势），AI 生成需求洞察报告 |
| **招标信息** | `/insights/bidding` | 多行业招标实时追踪（政务/制造/医疗/金融/教育/交通/能源/零售/农业），AI 分析高价值标段和投标策略，预算总额超 25 亿元 |
| **增长机会** | `/insights/opportunities` | 综合分析页，聚合所有子版块数据形成 6 大机会点 |

### 2.3 数据分析板块

| 模块 | 路径 | 功能说明 |
|------|------|----------|
| **数据大屏** | `/dashboard` | KPI 看板（今日PV/UV、累计PV/UV）+ Recharts 趋势图 + 页面访问排行 + 各模块访问趋势 + 实时访问记录 |
| **深度研报** | `/reports` | AI 生成的结构化商业研报（DeepSeek-V3 驱动） |
| **历史日报** | `/history` | GitHub Trending 历史快照，支持搜索和回溯 |

### 2.4 辅助功能

- **AI 智能客服**：RAG 增强的对话式问答，基于向量知识库检索 + DeepSeek 大模型生成
- **邮件订阅系统**：按订阅者配置的星期和时间自动发送洞察简报，支持单人立即发送与退订
- **页面埋点分析**：全站 PV/UV 实时统计，支持按页面、时间维度分析
- **系统设置**：邮件订阅管理、系统配置

### 3.1 数据源矩阵

| 数据源 | 采集方式 | 更新频率 | 存储 |
|--------|----------|----------|------|
| GitHub Trending | 实时爬虫（BeautifulSoup） | 每日 09:00 自动 + 手动触发 | SQLite |

- `github_trending` — GitHub Trending 项目数据（含日/周/月三维度）
- `baidu_hotsearch` — 百度热搜数据
- `competitor_news` — 友商动态新闻
- `bidding_opportunities` — 招标信息（含行业、预算、截止日期、相关度评分）
- `demand_signals` — 行业需求信号（含来源类型、行业、标签）
- `demand_reports` — AI 生成的需求洞察报告
- `email_subscribers` — 邮件订阅列表
- `page_visits` — 页面访问埋点数据
- `scrape_log` — 爬虫运行日志

## 四、技术架构

### 4.1 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    前端层 (Next.js 14+)                   │
│  React 18 · TypeScript · Tailwind CSS · Recharts         │
│  App Router · Server Components · Client Components       │
├─────────────────────────────────────────────────────────┤
│                    API 网关层                              │
│  Next.js API Routes (前端代理) + FastAPI (后端服务)        │
├─────────────────────────────────────────────────────────┤
│                    业务逻辑层                              │
│  数据采集引擎 · AI 分析引擎 · 邮件服务 · 埋点服务          │
├─────────────────────────────────────────────────────────┤
│                    AI/RAG 层                              │
│  DeepSearcher · Qdrant (向量DB) · SentenceTransformer     │
│  DeepSeek-V3 (LLM) · ModelArts (推理服务)                │
├─────────────────────────────────────────────────────────┤
│                    数据层                                  │
│  SQLite (主数据库) · Qdrant (向量数据库) · 文件存储         │
└─────────────────────────────────────────────────────────┘
```

### 4.2 技术栈详情

| 层次 | 技术选型 | 说明 |
|------|----------|------|
| **前端框架** | Next.js 14+ (App Router) | React 服务端组件 + 客户端组件混合渲染 |
| **UI 框架** | Tailwind CSS + 自定义组件 | 极简 B 端商业风格（类 Vercel/Linear），Mona Sans 字体 |
| **数据可视化** | Recharts | 面积图、折线图、柱状图、饼图，用于 PV/UV 趋势、行业热力图 |
| **图标库** | Lucide React | 统一的图标体系 |
| **后端框架** | FastAPI (Python) | 高性能异步 API，处理 AI 文本解析与数据采集 |
| **AI 模型** | DeepSeek-V3 / ModelArts | 大语言模型，用于结构化报告生成、智能问答、招标分析 |
| **RAG 引擎** | DeepSearcher (zilliztech) | 检索增强生成，支持深度研究和多轮推理 |
| **向量数据库** | Qdrant (本地文件模式) | 无需服务器，持久化到磁盘，存储 5 个知识集合 |
| **Embedding** | SentenceTransformer (BAAI/bge-m3) | 本地多语言嵌入模型，支持中英文，1024 维 |
| **关系数据库** | SQLite | 轻量级，存储所有业务数据（爬虫数据、用户数据、埋点数据） |
| **定时任务** | APScheduler | 后台调度器，管理 5 个定时任务（GitHub采集、招标采集、需求采集、邮件发送、数据清理） |
| **爬虫** | Requests + BeautifulSoup | GitHub Trending、百度热搜实时爬取 |
| **邮件服务** | SMTP (QQ邮箱) | 每日洞察简报自动发送 |
| **部署** | Windows Server 2022 | 前端端口 3000，后端端口 8000 |

### 4.3 RAG 知识库架构

平台构建了 **5 个向量知识集合**，支持跨集合语义检索：

| 集合名称 | 内容 | 分块策略 |
|----------|------|----------|
| `platform_knowledge` | 平台功能文档、技术栈说明 | 800 字符/块 |
| `demand_signals` | 行业需求信号（政策/招标/报告/趋势） | 500 字符/块 |
| `competitive_news` | 友商动态新闻 | 500 字符/块 |
| `github_trending` | GitHub Trending 项目数据 | 500 字符/块 |
| `policies` | 政策法规信息（等保/信创/数据出境等） | 500 字符/块 |

**检索流程**：用户提问 → SentenceTransformer 向量化 → 跨 5 个集合并行检索 → 按相关度排序 → 拼接上下文 → DeepSeek 生成回答

### 4.4 定时任务调度

| 任务 | 执行时间 | 功能 |
|------|----------|------|
| `demand_daily` | 每日 08:00 | 采集行业需求信号 |
| `bidding_daily` | 每日 08:30 | 采集招标信息 |
| `github_daily` | 每日 09:00 | 爬取 GitHub Trending |
| `scheduled_email` | 每分钟检查 | 按订阅者星期和时间发送洞察邮件 |
| `cleanup` | 每日 03:00 | 清理 30 天前历史数据 |

## 八、总结

InsightPro 作为一款 AI 驱动的商业洞察平台 MVP，已构建了完整的 **数据采集 → AI 分析 → 可视化展示 → 自动分发** 闭环。平台覆盖 9 大行业、5 大竞品、6 大政策领域，通过 RAG 技术实现了基于内部知识库的智能问答和深度研究能力。

**核心竞争力**：

1. **AI 原生**：全流程 AI 赋能（报告生成、竞品分析、招标研判、智能客服）
2. **RAG 架构**：DeepSearcher + Qdrant 向量检索，确保回答基于真实数据
3. **自动化**：5 个定时任务 + 每日邮件简报，无需人工干预
4. **全景覆盖**：从行业宏观到招标微观，从技术趋势到政策法规

**下一步关键动作**：

1. 接入真实数据源（替换预置数据池）
2. 实现用户认证体系
3. 迁移至 PostgreSQL + pgvector
4. 实现报告导出功能
5. 容器化部署 + CI/CD
