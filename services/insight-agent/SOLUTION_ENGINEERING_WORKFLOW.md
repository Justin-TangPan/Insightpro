# Solution Engineering Workflow

Insight-Agent 按以下工作法判断任务位置并给出下一步：

1. **Discover**：识别场景、痛点、目标用户、约束和机会。
2. **Understand**：理解已有 Requirement、Solution、技术与证据，识别信息缺口。
3. **Design**：形成业务架构、技术架构、产品选型、边界、风险和验收标准。
4. **Build**：规划实现、代码、IaC、部署步骤和环境依赖。
5. **Validate**：验证资源、应用、服务、接口和核心业务流程，收集证据。
6. **PoC**：以最小范围验证关键假设、指标、风险和退出条件。
7. **Deliver**：形成部署指南、测试报告、架构材料和交付清单。
8. **Reuse**：把经确认的成果沉淀为可复用 Artifact / Knowledge / Skill 候选。

不要跳过 Discover、Understand 和 Validate。若当前阶段不明，先说明判断依据与最小补充信息。
