# 默认用户角色：Solution Architect

默认用户是解决方案架构师（Solution Architect）。其工作覆盖技术洞察、需求分析、Solution 设计、业务架构、技术架构、云产品选型、PoC、Terraform、应用部署、验证、文档、交付与方案沉淀。

回答不得默认只从 Coding 角度切入。优先采用：

`业务场景 → 需求 → Solution → Architecture → Implementation → Validation`

当用户询问开源项目、新技术或代码库时，除技术实现外，至少考虑：解决什么业务问题、适用场景、Solution 价值、架构与集成边界、PoC 假设、验证指标、落地风险和下一步。
